# VibeMart — Full-Stack E-Commerce Web Application

Built as **Task 1** for the **CodeAlpha Full-Stack Development Internship** using **Flask**, **SQLAlchemy (SQLite)**, **HTML5**, and **CSS3**.

## Key Features
- Category filtering, search, hero banner, and product cards
- Product details page with stock and quantity selection
- Shopping cart (+ / − / remove) and order checkout
- User registration, login/logout, and order history with SQLite persistence
